WebGPU GitHub

Typed questions in, calibrated probabilities out.

Give the model a state and a set of typed questions (choice, score, noul). Every question is answered in a single forward pass with no text generation: the answer is read straight from the label logits. Everything runs on your GPU through WebGPU; nothing leaves the browser.

Not loaded. Weights stream from the Hugging Face Hub and are cached by the browser.
